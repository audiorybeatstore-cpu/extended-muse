# Extended Muse — Tailwind CDN storefront

This is the first responsive frontend build based on the supplied Extended Muse reference.

## Files
- `index.html` — page structure and Tailwind CDN setup
- `styles.css` — visual styling, responsive breakpoints, typography and sections
- `app.js` — mobile drawer, search, cart drawer, account modal and newsletter interactions
- `assets/` — put the real product/hero images here

## GitHub
Create a repository and upload all files while preserving the `assets` folder.

The design intentionally has no browser `alert()` calls. Messages appear inline or as a small styled toast.
